# ГРАНАТ — демонстрационный сайт

Четыре статические страницы на HTML, CSS и JavaScript. Без сборки, сторонних библиотек, сервера обработки заказов и платных API. Все фотографии взяты из исходной папки `images`, оригиналы сохранены.

## Файлы

- `index.html` — главная страница.
- `assortment.html` — ассортимент, цены и фильтры категорий.
- `contacts.html` — контакты и место для будущей карты.
- `delivery.html` — каталог доставки, корзина и форма заказа.
- `css/styles.css` — оформление и адаптация для телефона.
- `js/data.js` — единый список товаров, цен и реквизитов магазина.
- `js/app.js` — общее меню и подвал, фильтры, корзина и проверка формы.
- `images/` — фотографии павильона и продуктов.

## Изменение данных

В `js/data.js` меняйте массив `products`: название, категорию, цену, единицу и имя фотографии. Идентификатор `id` должен быть уникальным. Цены тестовые. Для орехов, напитков и чая используется общий снимок полок, что отмечено на карточках. Перед публикацией подтвердите ассортимент и замените общие фотографии на снимки конкретных товаров при необходимости.

В объекте `shop` того же файла замените «Уточнить адрес», «Уточнить телефон», «Уточнить ФИО» и «Уточнить ИНН» на подтверждённые данные. Режим работы: ежедневно с 8:00 до 22:00. Место для карты находится в `contacts.html`; после уточнения адреса его можно заменить бесплатной встроенной картой.

## Локальный запуск

Из корня репозитория выполните:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте сайт на локальном порту 8000. Останавливайте сервер сочетанием Ctrl+C. Устанавливать зависимости не требуется. Используйте HTTP-сервер, а не открытие HTML как локального файла.

## Корзина и заказ

Корзина хранится в `localStorage` браузера, сохраняется между страницами и после перезагрузки. Если хранилище недоступно, корзина работает до перехода на другую страницу. Количество — целое число единиц товара (кг, шт. или упаковок), максимум 999. Сумма не включает доставку. Можно добавить, увеличить, уменьшить и удалить товар. Форма проверяет имя, телефон, адрес и непустую корзину. Контактные данные не сохраняются; запросы с заказом никуда не отправляются. Успешное сообщение означает только формирование демонстрационного заказа.

## Публикация

После подтверждения реквизитов и цен загрузите файлы в основную ветку GitHub. В настройках репозитория откройте Pages, выберите публикацию из ветки `main` и папки `/ (root)`. Сборка не нужна. Все пути относительные, поэтому сайт подходит для GitHub Pages внутри пути репозитория. Другой вариант — любой хостинг статических файлов.

## Проверка перед публикацией

Откройте все четыре страницы, проверьте меню и изображения. На телефоне проверьте отсутствие горизонтальной прокрутки. На странице доставки добавьте товары, измените количество, удалите позицию и проверьте сумму. Перейдите на другую страницу и вернитесь: корзина должна сохраниться. Проверьте обязательные поля и сообщение об успешном демонстрационном заказе.
